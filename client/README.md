## 多客户端支持

ShadowStore 现已提供多客户端专属支持页面，方便不同代理工具用户快速获取和安装相应的模块

> 本功能暂未正式发布，当前仅在下方地址中提供试用
> 
> **访问地址**：[shadowstore.dpdns.org/client](https://shadowstore.dpdns.org/client/)

#### 当前支持的客户端

> 现阶段也已支持以下客户端：
>
> * **[Shadowrocket](https://shadowstore.dpdns.org/client//?c=shadowrocket)**
> * **[Surge](https://shadowstore.dpdns.org/client/?c=surge)**
> * **[Egern](https://shadowstore.dpdns.org/client/?c=egern)**

#### 如何切换客户端

> 提供以下两种客户端切换方式：
> 
> **页面快捷切换**
> 
> > 打开 [网页](https://shadowstore.dpdns.org/client/) 后，**长按** 页面左上角的 **`Shadow`** 文字，即可在弹出的菜单中快速切换
> 
> **地址参数直达**
> 
> > 支持在地址中以路径参数的形式直接访问对应的客户端网页。支持的参数包括：`c`、`v` 以及 `client`
> > 
> > > **参数使用示例：**
> > > 
> > > ```url
> > > https://shadowstore.dpdns.org/client/?c=shadowrocket
> > > ```
> > > 
> > > ```url
> > > https://shadowstore.dpdns.org/client/?v=surge
> > > ```
> > > 
> > > ```url
> > > https://shadowstore.dpdns.org/client/?client=egern
> > > ```
